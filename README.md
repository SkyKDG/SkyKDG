## 📦 Download

**[Icarus Workshop](https://github.com/SkyKDG/imm-workshop-releases/releases/latest)** · [![Latest release](https://img.shields.io/github/v/release/SkyKDG/imm-workshop-releases?label=latest&color=89b4fa&style=flat-square)](https://github.com/SkyKDG/imm-workshop-releases/releases/latest)

A Windows mod manager for *Icarus*: merge and edit EXMOD packs, pull from the community database, share mod lists with friends, stage UE4SS mods, plus an optional server agent for dedicated servers. Built with Python + PySide6 and shipped through GitHub Actions. The source is private; the releases are public.
